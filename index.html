02怎么用

推荐顺序

  1. 先读：打开「朗读版」，先不看中文，读一遍英文（生词已高亮）。
  2. 再听懂：点「朗读本节」或顶部的全文播放，0.75× 对照文本听一遍。
  3. 查漏：回到「讲义」，只看当节词条和 PET 链接。
  4. 做题：去「听力练习册」做对应那一节的填空题。
  5. 默写：朗读版文末的拼写测验，答错的自动进「错题本」，隔天再刷。

在电脑上打开

直接双击 index.html。建议 Chrome / Edge / Safari。

在手机上看

在本目录执行 python3 -m http.server 8765，手机连同一 Wi-Fi，访问 http://电脑IP:8765/。

iPhone 的「文件」App 直接预览 HTML 不执行脚本、也不播音频，请用 Safari 或上面的本地服务器。
